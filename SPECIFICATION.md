# Specifikation – Gravregister

Specifikationen är uppdelad i:

1. **[Allmän modell](docs/specifikation-generell.md)** – Begrepp och fält som kan gälla för gravregister i allmänhet: gravplats (kyrkogård, kvarter, gravplatsnummer), gravrättsinnehavare, närmast anhörig, gravsatta, skiss, extramaterial, lagring och export. Oberoende av ett specifikt arkivformat.

2. **[Gravregisterkort från Härnösands domkyrkoförsamling (Skandix/Remington System Sy)](docs/specifikation-harnosand-skandix.md)** – Det format som gäller för detta källdata: källmaterial (1 PDF per sida), mappar och kyrkogård/kvarter (HKG/HKN), struktur med tre sidor per gravplats, beskärning (splits), fältordning och specialfall.

Applikationen Gravregister bygger på den allmänna modellen och stödjer i dagsläget arkivformatet för Härnösands domkyrkoförsamling; andra format kan läggas till senare.
